# Codex Atlas
## Permission ergonomics (John's rule)
No permission prompts that annoy John when they can be avoided — prefer safe pre-allowed tools, batch calls, avoid needless escalation. If a permission is genuinely needed (or multiple agents need it), that's fine — never hold back or degrade the work to dodge a prompt. Avoid the avoidable prompts; keep the necessary ones. Dangerous / irreversible / outward-facing / money actions still confirm.
