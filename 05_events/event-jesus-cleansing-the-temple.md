# Event Jesus Cleansing The Temple

The Gospel pericope (Mark 11:15–19; Matt 21:12–17; Luke 19:45–48; John 2:13–22) in which Jesus drives the money-changers from [[solomons-temple-second|the Temple]] precinct; in John's telling Jesus speaks the line "destroy this temple..." which the Gospel reads as foreshadowing the resurrection.
