# Schema — Theme Node

Recurring motifs that cut across traditions. These are the edges of our cross-tradition map.

## YAML frontmatter

```yaml
---
type: theme
id: ""                              # e.g., "flood-motif", "dualism-cosmic", "demiurge", "dying-rising-god"
name: ""
category: ""                        # cosmogonic | eschatological | soteriological | ethical | ritual | political-theological | anthropological
appearances: []                     # links to 02_documents/ where this theme appears
deity-instances: []                 # links to 03_deities/ that embody this theme
status: "stub"
refs: []
tags: []
---
```

## Body

```markdown
# [Theme Name]

## Definition
What is this motif? Precise enough to be diagnostic — when do we say a text "has" this theme vs. when do we say it doesn't?

## Earliest attestations
By tradition, where do we first see this motif?
- Mesopotamian: `[[document-slug]]` (date)
- Egyptian: `[[document-slug]]` (date)
- Vedic: `[[document-slug]]` (date)
- etc.

## Variants
How does the motif morph across traditions? What stays constant, what changes?

## Connections claimed
- Direct borrowing claims: who has argued which tradition borrowed from which? Cite scholars.
- Independent-development claims: who argues these arose independently?

## Refs
1. ...
```
