## Aniconic by tradition

- `amma-dogon` — Dogon Amma is explicitly aniconic; the deity is the
  "speech-egg of the world" and is invoked through ritual, not depicted.
- `wakea` — Hawaiian Wākea cult focuses on prayer/oral tradition; no
  iconographic standard.
- `cagn` — San |Kaggen "takes the shape of a praying mantis" — but there
  is no fixed iconographic representation in San rock-art; San tradition
  is oral.
- `waa-the-crow` — Kulin Nation crow-ancestor is invoked through stories
  and Country, not images. Aboriginal Australian deities largely aniconic.
- `yaghuth` · `yauq` · `suwa` (Quranic-preserved pre-Islamic Arabian) —
  Suwāʿ got a contextual statuette match; Yaghuth and Yaʿūq did not.
  Tradition is iconoclastic post-Islam.

## Wikipedia entity conflicts (deity ID lost to a more-famous homonym)

- `danu` — Wikidata default is "Danuta" given name. The Irish goddess
  has no agreed iconography; Tuatha Dé Danann sometimes shown but Danu
  herself is not depicted.
- `laz` — Wikidata default is Lazare Carnot (French statesman). Akkadian
  Laz has no extant iconography.
- `tir-armenian` — Wikidata returns Turkish village "Tir, Yenice".
  Armenian Tir (god of writing) has no extant image.
- `vac-goddess` — Wikidata returns Czech male given name "Václav".
  Vedic Vāc is a hymnic/abstract deity — usually identified with
  Sarasvatī in later iconography, so a standalone image is hard to
  defend.
- `cagn` — Wikidata returns French commune Cagnes-sur-Mer.
- `haoma-zoroastrian` — Wikidata returns Samurai Shodown character

  (Ephedra/etc.), which has been documented elsewhere.
- `menvra-etruscan` — Wikidata Q126916 collapses Etruscan Menrva into
  Roman Minerva; Minerva's iconography is not specifically Etruscan.
