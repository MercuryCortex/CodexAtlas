# Consciousness Key Figures — canonical inventory

**Date:** 2026-05-23
**Handle:** opus-consciousness-lens-spec-1 (companion doc to `AUDIT/consciousness-lens-spec-2026-05-23.md`)
**Status:** PROPOSAL — awaiting John's greenlight/veto. READ-ONLY scoping document; no nodes created, no existing nodes touched.

This is the inventory of the ~50 canonical FIGURES the `31_consciousness/` lens needs. Each gets a person-node in `04_persons/` (already the convention) AND a figure-node in `31_consciousness/figures/<slug>.md` (proposed). The two are cross-linked: the person-node carries biography; the figure-node carries the consciousness-lens claim summary with primary-work + tier + risk-flag (where applicable) + claim summary + cross-lens connections.

Per the parent spec CON-1 (perennialist↔contextualist symmetric pairing) and CON-2 (neuroscience-finding ≠ popular-extrapolation discipline), the catalog is organized by **research stream**, not chronologically — every Stace has a Katz, every Forman has a Proudfoot, every Carhart-Harris (T1 neuroscience) is paired with the popular-extrapolation figure (Pollan, Hancock) whose tier-relative-to-Carhart-Harris is documented.

**Field key:**
- **Slug** — kebab-case canonical id (also the `04_persons/` and `31_consciousness/figures/` filename)
- **Dates** — birth/death (or `b. ` if living)
- **Discipline** — primary field
- **Work** — 1-3 main consciousness-lens primary texts
- **Tier** — per CODEX v1.1 (T1 mainstream / T2 minority / T3 alternative / T4 popular-rejected / T5 disclaimer-required)
- **Risk** — `political-risk-flag: true/false/partial` per peer-reviewed source where applicable (most consciousness-lens figures = no flag; T5 cross-link figures = mandatory flag)
- **Source** — peer-reviewed academic anchor citing the figure as a consciousness-lens subject
- **Claim** — 1-line summary of their consciousness-lens position
- **Connections** — which `03_deities/` / `06_themes/` / `22_practices/` / `14_rituals/` / `24_pharmacology/` nodes their work engages
- **Include** — `first-batch` / `stub` / `later-wave` / `T5-opt-in`
- **Primary home** — `31_consciousness/figures/` (most) or `29_philosophy/figures/` (philosophy-of-mind-anchors) or `04_persons/` only (with cross-link)
